# TALSHYK — сайт села

Публичная статическая версия информационного сайта села Талшык. На страницах есть новости и объявления, афиша, инициативы, сведения о селе и карта OpenStreetMap. Регистрация, вход, профиль, локальные голоса и демо-панель администратора сохраняются в браузере пользователя.

Данные аккаунтов, инициатив и голосов хранятся отдельно на устройстве в `localStorage`; между разными людьми и устройствами они не синхронизируются. Пароль хранится только в виде PBKDF2-хеша с солью. Первый аккаунт в каждом браузере получает локальную админ-панель. Это демонстрационная роль: её можно обойти через инструменты браузера, а изменения видны только на этом устройстве. Общая база и защищённая админ-панель требуют серверной версии. Полную серверную версию можно запускать из основного приватного репозитория.

GitHub Actions автоматически публикует папку `docs/` в GitHub Pages после изменений в `main`. Основные файлы сайта: `docs/index.html`, `docs/pages.js` и CSS-файлы в `docs/`.
