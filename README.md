# TALSHYK — сайт села

Публичная статическая версия информационного сайта села Талшык. На страницах есть новости и объявления, афиша, демонстрационные инициативы, сведения о селе и карта OpenStreetMap. Регистрация, вход, профиль и личные голоса сохраняются в браузере пользователя.

Данные аккаунтов и голосов хранятся отдельно на устройстве в `localStorage`; между разными людьми и устройствами они не синхронизируются. Пароль хранится только в виде PBKDF2-хеша с солью. Голоса учитываются только в этом браузере, карточки идей демонстрационные. Общая база, публикация инициатив и панель администратора требуют серверной версии. Полную серверную версию можно запускать локально из основного приватного репозитория.

GitHub Actions автоматически публикует папку `docs/` в GitHub Pages после изменений в `main`. Основные файлы сайта: `docs/index.html`, `docs/pages.js` и CSS-файлы в `docs/`.
